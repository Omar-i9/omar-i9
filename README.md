# Omarr — Personal Space V5.2

موقع هوية شخصي مستقل، مبني بمشاهد قصيرة وانتقالات اختفاء وظهور تدريجية، مع الحفاظ على الروابط والميزات الأساسية الموجودة في مستودع `Omar-i9/omar-i9`.

## ما تتضمنه النسخة

- صورة الحساب الحقيقية من المستودع الأصلي، مع بديل JPEG عند فشل تحميل WebP.
- 15 حساباً ومنصة اجتماعية من الريبو؛ 14 رابطاً تفتح المنصة مباشرة، وDiscord ينسخ المعرّف لأن المصدر لا يتضمن رابط حساب عام.
- ملفات SVG الأصلية للمنصات تُحمّل مباشرة من `Omar-i9/omar-i9/assets/icons/social`، وأيقونات الألعاب من `assets/icons/gaming`.
- قسم معرّفات الألعاب الستة مع إمكانية نسخ كل معرّف.
- تذييل مختصر بثلاث روابط فقط: Instagram وSnapchat وGitHub.
- زر مشاركة يعرض المشاركة الأصلية على الأجهزة المدعومة، أو نافذة بها QR محلي ورابط قابل للنسخ.
- بطاقة TAAMEN صغيرة بعبارتين منفصلتين: فتح الموقع الحي، وفتح صفحة معلومات المشروع.
- صفحة تعريف مستقلة بـ TAAMEN 2.1، تشرح مزايا النسخة القادمة وتفصل ما زال قيد التطوير عن الوظائف العامة.
- أيقونة تبويب مأخوذة من الصورة المرفقة، وشعار TAAMEN معتم بخلفية بيضاء.
- خلفية Aurora تجمع الصورة المرجعية مع شرائط لونية متحركة وتفاعل ضوئي خفيف مع المؤشر.
- تأثير ابتعاد وميل ثلاثي الأبعاد لبطاقة الصورة عند تحريك المؤشر حولها، مع تعطيله على اللمس واحترام تقليل الحركة.
- واجهة عربية وإنجليزية مع RTL/LTR.

## تشغيل المشروع

يتطلب Node.js 20.19 أو أحدث من خط 20، أو 22.12 فأحدث من خط 22، وفق متطلبات Vite 8.

```bash
npm install
npm run dev
```

افتح `http://localhost:4173/`.

لإنشاء نسخة الإنتاج:

```bash
npm run build
```

لفحص JavaScript والاختبارات:

```bash
npm run check
```

## بيانات وروابط المشروع

روابط الحسابات ومعرّفات الألعاب وأسماء ملفات SVG منقولة من `data/social.js` و`assets/icons` في مستودع `Omar-i9/omar-i9`. يتم تحميل SVG مباشرة من GitHub Raw، لذلك يلزم اتصال إنترنت لظهور شعارات المنصات. صورة الملف الشخصي كذلك من مستودعك العام.

شعار TAAMEN في البطاقة وأيقونة التبويب تم توليدهما محلياً من الصورة التي أرفقتها، مع خلفية بيضاء معتمة لإظهار الشعار بحجم صغير.

## بطاقة TAAMEN

المعروض هو تعريف للنسخة القادمة TAAMEN 2.1، وليس إعلاناً عن إطلاق مكتمل. ملخص المزايا مبني على بيانات مشروع الموقع وسجل V22.3 المرفق: مركز المباريات والأرشيف، الخطط التكتيكية 5v5 و7v7، ملفات اللاعبين والتحليلات، أدوات تحرير الصور، تحسينات الهاتف، ومسار مزامنة سحابية بموافقة صريحة. تكامل خدمات السحابة والذكاء الاصطناعي قد يحتاج إلى إعداد منفصل، ولا يوجد موعد إطلاق رسمي معلن في المصدر.

## فحوص ما قبل النشر

- افتح الصفحة الرئيسية وصفحة `projects/taamen.html`.
- اختبر الروابط الخارجية الخمسة عشر، ونسخ Discord ومعرّفات الألعاب.
- اختبر المشاركة الأصلية ونسخ الرابط وظهور QR.
- اختبر حركة بطاقة الصورة على سطح المكتب، وتأكد من تعطيلها على الشاشات اللمسية.
- اختبر العرض بعرض 320 و390 و768 و1440 بكسل، وحالة `prefers-reduced-motion`.
