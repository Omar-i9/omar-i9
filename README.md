# Omarr — Personal Space V5.2

موقع شخصي ثابت (Static Website) جاهز للنشر مباشرة على GitHub Pages.

## التشغيل والنشر

**لا يحتاج هذا الموقع إلى Node.js أو npm أو Vite أو package.json أو أي عملية Build.**

1. افتح المستودع `Omar-i9/omar-i9` على GitHub.
2. ادخل إلى **Settings → Pages**.
3. تحت **Build and deployment** اختر **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/(root)` ثم اضغط **Save**.
5. افتح رابط الموقع: https://omar-i9.github.io/omar-i9/

لا تفتح ملف `index.html` من واجهة استعراض الملفات في GitHub؛ هذه الواجهة تعرض الشيفرة كنص. افتح رابط GitHub Pages أعلاه لعرض الموقع.

## اختبار محلي بدون npm

من مجلد المشروع يمكن تشغيل خادم Python المدمج (اختياري):

```powershell
py -m http.server 8000
```

ثم افتح `http://localhost:8000/`. لا يحتاج ذلك إلى تثبيت حزم.

## ما يحتويه الموقع

- خمسة مشاهد: الهوية الشخصية، الحسابات الاجتماعية، معرّفات الألعاب، مشروع TAAMEN، والتواصل الختامي.
- 15 حساباً ومنصة، مع أيقونات SVG محفوظة محلياً داخل المستودع. Discord يتيح نسخ المعرّف لأن المصدر لا يتضمن رابط حساب عام.
- ستة معرّفات ألعاب مع إمكانية نسخها.
- مشاركة عبر Web Share API أو نسخ الرابط، دون مكتبات QR أو اعتماديات خارجية.
- بطاقة TAAMEN صغيرة بزر لفتح الموقع الحي وزر مستقل لصفحة معلومات TAAMEN 2.1.
- صفحة تفاصيل مستقلة للمشروع: `projects/taamen.html`.
- صورة Aurora وشعار TAAMEN وأيقونة التبويب محفوظة محلياً في مجلد `public`.
- انتقال تدريجي بين المشاهد، وتأثير ابتعاد بطاقة الهوية عن المؤشر مع ميل ثلاثي الأبعاد.
- واجهة عربية وإنجليزية ودعم RTL/LTR.
- احترام إعداد `prefers-reduced-motion` وتعطيل حركة المؤشر على أجهزة اللمس.

## بنية الملفات

- `index.html`: الصفحة الرئيسية.
- `projects/taamen.html`: صفحة تعريف TAAMEN.
- `src/`: JavaScript وCSS تعمل مباشرة في المتصفح بوحدات ES Modules وملفات CSS عادية.
- `public/`: الصور والأيقونات وملفات الموقع الثابتة.

## ملاحظات تقنية

- لا تستخدم الصفحة أي import من npm أو مكتبات JavaScript خارجية.
- روابط المنصات تفتح مباشرة، بينما الصور والأيقونات والأنماط والشفرة اللازمة للموقع موجودة داخل المستودع.
- صورة الحساب تستخدم الصورة العامة لحساب GitHub الرسمي. يلزم اتصال بالإنترنت لتحميل صورة الحساب فقط.
- بعض خصائص المشاركة تعتمد على دعم المتصفح؛ عند عدم توفر المشاركة الأصلية يظهر خيار نسخ الرابط.
- ملفات `robots.txt` و`sitemap.xml` موجودة في جذر الموقع لتتعرف عليها محركات البحث.
