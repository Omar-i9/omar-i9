# Omar Profiles v8.0.0 - Ayah Smooth + TikTok Alt

نسخة صقل جديدة تركّز على بطاقة الآية وحركة تبديلها، مع إضافة كارد TikTok إضافي بنفس منطق الكود المطلوب ولكن بشعار/ستايل مختلف عن كارد TikTok الأول.

## أبرز التغييرات

- تصغير بطاقة الآية أكثر على الهاتف حتى لا تعطل استخدام الموقع.
- جعل بطاقة الآية تنتقل تلقائيًا بين أعلى اليسار وأعلى اليمين حسب اللغة:
  - العربية: أعلى اليسار.
  - الإنجليزية: أعلى اليمين.
- منع تعارض بطاقة الآية مع زر تغيير اللغة.
- تحسين تبديل الآيات بسلاسة أكبر عبر fade/slide ناعم بدل تبديل مفاجئ.
- تحسين سحب بطاقة الآية باستخدام requestAnimationFrame و transform بدل تحديث left/top أثناء الحركة.
- تقليل التقطيع أثناء تحريك بطاقة الآية على الهاتف.
- إضافة كارد TikTok جديد للرابط:
  - https://www.tiktok.com/@gdmi33
- جعل كارد TikTok الجديد بستايل أيقونة مختلف عن TikTok القديم.
- تحديث Badge الإصدار إلى v8.0.
