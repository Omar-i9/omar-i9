# Omar Profiles v6.0.0 - Smart Polish

## Added
- Smart profile status based on the local time:
  - 00:00-08:00: sleeping/offline style.
  - 08:00-18:00: busy style.
  - 18:00-00:00: one random daily evening state: online, coding, or gaming.
- Background mode now follows the current profile status automatically.
- Avatar click micro-bio popover with Arabic/English text.
- Magnetic interaction for the hero buttons and share buttons on pointer devices.
- Low-power mode for weaker phones using device memory, CPU cores, Save-Data, and slow network hints.
- Stronger SEO/Open Graph/Twitter metadata.
- Version badge in the footer.
- Ayah progress ring instead of a text timer.
- Ayah detail mode gets a longer rotation timer.
- Copy ayah button appears only when tafsir/details are open.

## Kept intentionally
- Font Awesome CDN stayed as-is to avoid changing the icon system too much in this final polish.
- No manual background switch was added; the background follows the smart status automatically.
- No music card/player was restored.
