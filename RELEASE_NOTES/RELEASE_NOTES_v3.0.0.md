# v3.0.0 — Omar Profiles 3.0

**Adaptive Experience** · 2026-09-21

Omar Profiles 3.0 is a product release on the modular static hub. TAAMEN remains TAAMEN 2.0 (`v2.0.0`, Active). The two version numbers are not the same product.

## Project showcase

- Projects are compact selectable rows, not a pile of giant cards.
- One row open at a time. The header selects and deselects. Destination links live inside the expanded panel.
- TAAMEN public actions: Open TAAMEN and acquisition (`https://taamenn.com/acquisition`, USD 4,900, negotiable).
- TAAMEN GitHub, Releases, and GitHub Pages stay off the public surface.
- EV uses the same row architecture, with a HUD hint when collapsed and a fuller HUD when selected. Live + repository stay visible.

## Adaptive presence

- Status follows Asia/Hebron time from one schedule: school, rest, studying, online/coding/gaming, sleep on weekdays; Friday and Saturday include mosque, football, and evening variants.
- Atmosphere is a quiet 5–15% wash. Project brands do not recolor with status.

## Ayah, language, social

- Ayah 3.0: category, Arabic verse, English translation when the UI is English, reference, short meaning, explanation on demand, then New Ayah / Copy.
- Language control is a compact AR/EN switch.
- GitHub, TikTok, and Snapchat sit on a light brand-surface shell so the marks stay readable.

## What this is not

- Not a framework migration.
- Not a from-scratch redesign.
- Not a CSS cleanup release.
