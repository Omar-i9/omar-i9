بطاقات تقنية سريعة

الإصدار V5.x

المستودع يحتوي tag باسم v5.2، وملف الكاش الحالي يشير إلى v5-11-focused-ux-cleanup.

المعمارية Static SPA

صفحة HTML رئيسية، router بالهاش، وحدات ES modules، وبيانات محلية منفصلة.

التقنيات HTML/CSS/JS

لا يوجد build system أو npm. المشروع مناسب للنشر المباشر على GitHub Pages.

اللغة عربية أساسية

واجهة المشروع الأصلية RTL بالعربية، وصفحة العرض هذه تدعم العربية والإنجليزية.

النشاط 12

البيانات Local

يعتمد على data/site-data.js و data/injuries-data.js مع تخزين محلي للخيارات.

الأوفلاين SW Cache

ملف sw.js يجهز كاش للملفات الأساسية ويتجنب fallback خاطئ لملفات JS/CSS.

الرخصة غير موضحة

لم يظهر ملف LICENSE ضمن الملفات التي تم تحليلها، لذلك لم أضع ترخيصًا مفترضًا.

What Changed

Project Evolution

التغييرات لم تكن مجرد زخرفة: أغلب الإصدارات عالجت حدودًا عملية في التنقل، التخزين، الرادار، الخصوصية، والمساعد المحلي.

من صفحات إلى نظام routes

وجود router.js وقائمة validRoutes جعل التطبيق يعمل كـSPA ثابتة، مع انتقالات hash بدل صفحات منفصلة كثيرة.

بيانات مفصولة عن الواجهة

ملفات data/site-data.js و data/injuries-data.js جعلت تحديث المباريات والإصابات والتكتيكات أقرب لتحرير بيانات بدل تعديل layout.

جوال أقل ازدحامًا

وثائق V4 و V5.6 تشير إلى تقليل ازدحام الجوال، فصل صفحات المزيد، وتحسين جودة تفاعل AI على الشاشات الصغيرة.

خصوصية أوضح

تمت إضافة مركز خصوصية، إعدادات Cookies، حذف بيانات الجهاز، ورسالة صريحة بأن المفاتيح السرية لا توضع داخل ملفات الواجهة.

رادار أكثر استقرارًا

الرادار مر بدورة إيقاف ثم إعادة بناء، وهي إشارة نضج: حفظ الملفات، إصلاح التخزين، ثم العودة بمفاتيح v5 ومنطق جديد.

كاش أوضح

Service Worker يضع قائمة ملفات صريحة ويتجنب إرجاع HTML لطلبات JS/CSS عند الفشل، لتقليل أخطاء syntax في المتصفح.

Technical Heritage

الإرث التقني

نضج تدريجي لا قفزة واحدة

المستودع يوضح مشروعًا نما بإصلاحات متتابعة: صحة وقبلة، إصابات، رادار، تنقل، أمان، ثم AI. هذا يعطيه قيمة كأثر تقني لمسار تعلّم وتطوير عملي.

index.html
App shell واحد يحتوي الصفحات والحوارات والأزرار الأساسية.
js/app.js
نقطة boot تستدعي الساعة، الثيم، الراوتر، الخدمات، AI، الرادار، الإصابات، والقبلة.
router.js
تنقل hash routes مع active states وإغلاق قوائم الجوال والمزيد.
data
بيانات الموقع والإصابات منفصلة عن منطق العرض.
sw.js
كاش للأصول الأساسية وتعامل حذر مع الطلبات الخارجية والملفات البرمجية.
